# PatchForge 的工程边界

## 决策与执行分工

修复策略是模型驱动工具循环：read_file、search_code、replace_text、apply_edits、save_checkpoint、restore_checkpoint、run_tests、finish。runtime 按工具 schema 验证参数，不执行模型提供的命令。工具调用消息在运行内存中成组保存；持久化轨迹包含参数与观测，不展示模型私有推理。

初始源码选择限制为 24,000 个 JSON 字符，基于问题和基线失败词项排序，附带 AST 符号索引；不足以全部装入时明确标出片段。基线输出和预算说明另行追加。read_file 支持按行读取，最多 200 行、14,000 字符。完整请求历史预算为 60,000 字符，超限时整组压缩旧 assistant/tool 回合，保留初始上下文和最近三组；保护区仍超限则停止。字符预算不是精确 token 或金额上限。

每次替换都要求旧文本精确出现一次，避免模糊应用补丁。只有 task.editable 中已存在的文件可写，测试文件只读。路径拒绝绝对路径、父目录跳转、反斜线、符号链接与 Windows junction。

apply_edits 先在内存中按顺序暂存全部变更，验证精确匹配、体积与 Python 编译语法，再写入。验证失败不写任何文件，普通写入失败尝试恢复原始内容；这不是跨文件的断电原子事务。检查点只保存可编辑源码，回退会使旧测试结果失效。

## 验证绑定的是当前代码

修改使此前的 visible 结果失效。finish 无论之前结果如何都会重跑当前代码的可见测试；只有通过才执行一次保留测试。保留测试失败直接结束本次尝试，输出不进入下一轮模型上下文。没有重试挑最佳成绩。

测试开始与结束计算工作区 SHA-256，拒绝期间代码被改动；两套最终测试必须绑定同一版本。每个 run 保存任务快照，后续任务目录变更不会改变旧记录的 before 源码。ZIP 下载只装入明确允许的前后源码、公开任务信息和结果，并附逐文件摘要；终态后工作区摘要发生变化会拒绝打包。

相同测试内容出现在模型可见输入里不构成测试防作弊；模型可能针对测试特判。保留样例能发现一部分回归，不能证明算法普遍正确。任务描述、模型轨迹和最终 diff 都应人工检查。

## 执行隔离

每次测试创建一个临时 Linux 容器：网络 none、非 root 用户、只读根文件系统与工作区、drop ALL capabilities、no-new-privileges、192 MiB 内存、1 CPU、64 PID、限制打开文件数与文件大小、16 MiB 临时目录。仅挂载任务源码和测试，不挂载宿主项目、凭证目录或 Docker socket。容器使用已存在镜像，执行中不会拉取镜像或安装依赖。

这些限制减少宿主侧风险，不构成多租户的完整安全承诺；Docker daemon/内核漏洞与同进程测试篡改不在当前防护能力内。被测代码和 unittest 同进程，存在 monkeypatch、伪造结果等风险，所以不能将本验证器用于敌对代码评分。参考 [Docker 执行参数](https://docs.docker.com/engine/containers/run/) 与 [禁网模式](https://docs.docker.com/engine/network/drivers/none/)。

## 状态、取消与恢复

每个 run 一个独立副本，两个线程 worker，活动任务上限八个。SQLite 保存状态与审计事件；每次事件和状态写入是单个事务，但源码写入与 SQLite 事务不是分布式原子操作。进程崩溃后需要人工检查工作副本，不能承诺 exactly-once。

运行目录持有 OS 文件锁，拒绝另一个调度器同时打开相同目录。Docker tag 在运行时初始化时解析为 image ID，后续容器固定使用该 ID，避免标签更新造成前后测试镜像不同。

取消可停止容器测试并清理容器；模型 HTTP 请求最多等待其 transport timeout，返回后仍记录用量，但不继续执行工具。启动时将未完成状态标为 interrupted，不自动重放；创建新任务不会覆盖旧补丁。每个 run 的产物位于 runs/<id>/。

## 模型与对照

调用 DeepSeek 原生 function calling，无隐藏 HTTP 重试。direct 的一次输出可提交一组精确修改，runtime 自动执行同样的最终测试；repair 可主动读取遗漏源码与根据执行反馈重试。两种策略初始片段、失败输出和最终验证规则一致，但后续可获取信息与调用预算不同。因此比较的是完整策略，不单独归因于测试反馈或推理能力。

默认模型与工具协议参考 [DeepSeek 工具调用文档](https://api-docs.deepseek.com/guides/tool_calls/)。接口兼容不代表跨供应商效果一致。真实调用记录 total_tokens，缺失或失败时标记不完整，不将未知计费视作免费。
